# Security policy

FoliaRace is a development-time diagnostic tool. Do not attach the instrumentation agent to an untrusted production server without reviewing the enabled targets and configuration.

To report a security issue, open a private GitHub security advisory for `flennium/FoliaRace` when possible. Include the affected version, runtime/API version, configuration, and a minimal reproduction. Do not publish credentials, server logs containing secrets, or private plugin source.
